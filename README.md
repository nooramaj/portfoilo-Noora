# Noora Almajaideh — Portfolio

Personal portfolio site for Noora Almajaideh, Software Engineer and System Architect. Built with React 19, TypeScript, and Vite, styled with Tailwind CSS, animated with Framer Motion.

Live at [www.norah.work](https://www.norah.work).

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Deploy

Pushing to `main` builds the site and deploys it to GitHub Pages automatically via the workflow in `.github/workflows/deploy.yml`.
